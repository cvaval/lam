## 1. Objet

Klinik v3.0 a remplacé le codage **chromatique** des types de document par un codage
**typographique** : pastille uniforme — fond Pil, bordure `#C7C6C1`, texte Chabon, IBM Plex Mono
— portant un code de trois lettres.

La charte n'en prévoyait que **six**. La plateforme sert **huit** familles. Deux codes ont été
forgés à la migration v2.0 et signalés comme non avalisés.

## 2. Décision

> **`IDX` et `TAR` sont validés.**

| Code | Famille |
|---|---|
| `LÉG` | Éditions Le Moniteur |
| `BRH` | Circulaires de la Banque de la République d'Haïti |
| `JUR` | Jurisprudence |
| `DOC` | Législation annotée |
| `FIN` | Lois de finances |
| `MRK` | Marques de commerce et de fabrique |
| **`IDX`** | **Index du Moniteur** |
| **`TAR`** | **Tarifs douaniers** |

Aucun effet chromatique : les huit partagent la même pastille. Seul le badge « Dokiman verifye »
porte Sitwon.

## 3. Réserve — divergence de libellés, non résolue

L'avenant retient des libellés **taxonomiques** ; la plateforme emploie des noms de **service**,
qui paraissent en navigation et dans les URL. Ils n'ont pas été alignés.

| Code | Plateforme (service) | Avenant (taxonomie) |
|---|---|---|
| LÉG | Éditions Le Moniteur | Législation |
| DOC | **Législation annotée** | **Doctrine** ← divergence la plus nette |
| MRK | Marques de commerce & de fabrique | Marques enregistrées |
| IDX | Index du Moniteur | Index et répertoires / *Endèks* |
| TAR | Tarifs douaniers | Tarifs douaniers / *Tarif ladwàn* ✓ |

C'est une décision **produit**, non de charte : renommer un service change la navigation et les
URL. Elle reste ouverte. Les libellés des deux nouveaux types sont donnés « proposés, à
confirmer » — rectification par **AV-01*bis*** le cas échéant.
